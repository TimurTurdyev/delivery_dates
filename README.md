# Delivery Dates

Сроки доставки на странице товара для OpenCart 2.3 / ocStore 2.3. Покупатель видит, например, "Самовывоз - сегодня, Курьер - 26-27 октября, 300 р.". Даты считаются от текущего дня с учетом выходных, праздников и времени приема заказов.

## Установка

1. Залить `upload/` в корень сайта.
2. Поставить `install.xml` через установщик расширений (можно упаковать с `upload/` в `delivery_dates.ocmod.zip`), затем обновить модификаторы.
3. Установить модуль "Сроки доставки в карточке товара" и включить его.

В стандартной теме сроки выводятся над опциями и кнопкой "Купить". В своей теме нужно вставить `<?php echo $delivery_dates; ?>` в шаблон товара.

## Сроки

Способы доставки задаются для товаров в наличии и для каждого статуса, который ставится при нулевом остатке ("Предзаказ", "2-3 дня"). Срок в рабочих днях: 0 - в день отправки, 2 или 2-3. Если срока нет, выводится название и стоимость.

Для статуса можно указать свой текст наличия, например "Под заказ".

## Календарь

После времени приема и в выходные отсчет идет от следующего рабочего дня. Выходные отмечаются по дням недели, праздники вписываются через запятую: `01.01` повторяется ежегодно, `31.12.2019` действует в 2019 году. Время сервера видно в настройках.
